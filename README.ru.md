# InnoRouter

> Перевод API 5.x переведён в архив. Актуальная документация InnoRouter 7 пока
> доступна на [английском](README.md) и [корейском](README.ko.md) языках.

InnoRouter 7 использует macro-first модель: одно объявление `@Router` открывает
единые `RouterStore`, `RouterState` и `RouterAction`.
