# InnoRouter

> Diese Übersetzung dokumentiert die archivierte 5.x-API nicht mehr. Die
> aktuelle, grundlegende InnoRouter-7-Dokumentation ist vorerst auf
> [Englisch](README.md) und [Koreanisch](README.ko.md) verfügbar.

InnoRouter 7 ist macro-first: Eine `@Router`-Deklaration erzeugt den Zugang zu
einem `RouterStore`, einem `RouterState` und einer `RouterAction`-Sprache.
