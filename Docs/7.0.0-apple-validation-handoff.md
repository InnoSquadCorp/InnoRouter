## Environment admission

Run `xcodebuild -version`, `xcrun swift --version`, `xcodebuild -showsdks`, and
`xcrun simctl list devices available` and retain their output. The package
requires Swift 6.3+, iOS/iPadOS 18+, macOS 15+, tvOS 18+, watchOS 11+, and
visionOS 2+. Use an Xcode/SDK combination actually providing the chosen compiler
and platform, with separately recorded Swift 6.3 minimum and Swift 6.4 forward
lanes. A compiler version inferred from an Xcode marketing version is insufficient.
Native macOS scene probes require a logged-in GUI session. iPadOS and visionOS
probes require dedicated, already booted compatible simulators; substitute
verified UUIDs, never guessed device names. Missing SDKs or simulators are
unverified gates rather than successful skips. Do not change the user's selected
Xcode, simulator settings or existing app processes without permission.
