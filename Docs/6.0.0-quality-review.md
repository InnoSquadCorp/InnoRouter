# InnoRouter 6.0.0 quality follow-up

- Reviewed: 2026-09-05
- Scope: the local macro-first 6.0 candidate, including its planned 6.1–6.3 work
- Specification: [functional-expansion-spec.md](functional-expansion-spec.md)
- Approval status: the specification describes an implemented local candidate;
  this reconciliation is provisional until maintainer release review.

## Findings and implementation

| Priority | Finding | Resolution | Regression evidence |
| --- | --- | --- | --- |
| P1 | An `Int.max` migration start could overflow while checking adjacency. | Check positive, below-current start versions before arithmetic. | `RouterSnapshotTests.migrationAboveCurrentVersion` |
| P2 | Nonpositive snapshot schemas were reported as migration gaps. | Return `invalidSnapshotVersion` and retain that reason during explicit recovery. | `RouterSnapshotTests.invalidSnapshotVersion` |
| P2 | Serialized action sequences lost per-action context, changing source-sensitive policy behavior. | Store `RouterActionStep` values and replay their individual contexts through production. | `RouterActionSequenceTests.contextualReplay` and the independent consumer |
| P2 | Support bundles exported successfully but lacked a first-class reopen path and accepted unknown format versions. | Validate the format during decoding; import bundles through the Recorder and native file picker. | `RouterInspectorDiagnosticBundleTests` and the independent consumer |
| P2 | Entry preflight did not account for escaped or duplicated envelope keys. | Scan the exact snapshot envelope, recognize escaped keys, and reject duplicates before entry decoding. | Envelope regression cases and 4,000 deterministic snapshot/bundle mutations |
| P2 | Replacing a timeline retained timing from earlier live transitions. | Clear timing correlation on replace and prune it after bounded append. | `RouterInspectorDiagnosticBundleTests.replaceClearsTiming` |
| P2 | Signpost adapter teardown could leave intervals open, and ownership had only smoke coverage. | Use a testable interval owner that closes outstanding work during teardown. | `RouterSignpostTrackerTests`: 14 terminal outcomes, interleaving, repeated starts, and teardown |

Snapshot construction and decoding also discard orphan bookmarks, preserving
the same invariant as Recorder import.

## Requirement reconciliation

This follow-up rechecks four requirements: FR6-007 (restoration), FR6-031
(Inspector workflows), FR6-033 (bounded imports), and FR6-035 (diagnostics and
reproduction). All four have implementation and regression evidence after the
fixes; no missing or contradictory behavior remains in that reviewed scope.
The other 31 requirements retain their existing traceability and full-suite
coverage; this report does not claim a new feature-by-feature audit of them.

No second navigation authority or test-only reducer was introduced. The runtime
continues to use `@Router`, `RouterStore`, `RouterAction`, and `RouterPlan`.
Public API budgets are now 933 runtime, 153 Inspector, and 38 Testing symbols.
The unpublished sequence fixture changes from action-only JSON to contextual
steps before the first 6.0.0 tag.
