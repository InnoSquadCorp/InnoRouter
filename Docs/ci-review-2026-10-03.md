  trusted coordinator still observes eligibility changes.

  without publishing another `CI Required` verdict. Exact native run/check/blob
  proof allows current real CI to remain the readiness input in both rollout modes.
- Non-PR CI notices no longer allocate the Dependabot inspector.
- Replaced unchecked archive extraction and broad queue lint ignores with a
  checksum-verified linter and one exact release queue compatibility exception.

Fresh checks: 60 Python tests, 695 Swift Testing tests (one intentionally expected
known issue), workflow lint across 11 workflows, public operations, reusable
concurrency and optimization contracts, and `git diff --check`.

label under-selection, then passed on the changed implementation.

The existing 24 protected legacy checks and `INNOROUTER_CI_AGGREGATE` rollout
setting are preserved. During this transition, documentation/source events still
run the legacy gates; further savings require a separately reviewed protection
migration. Base-retarget trigger migration is also outside this change. Labels
are the only metadata events newly isolated here; body edits were already absent
from the primary CI trigger.
