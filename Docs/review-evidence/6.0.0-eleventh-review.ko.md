## 공개 계약과 migration

- `RouterScenarioFixture.currentFormatVersion`은 6이다. format 5 이하는 Feature ownership을 표현하지 못하므로 명시적으로 거절한다.
- Feature plan replay 시 `RouterScenarioFeatureResolver`를 등록해야 한다. macro-generated `Feature` mapping을 `RouterScenarioFeatureProjection`에 전달하는 것이 기본 경로이며 수동 mapping도 같은 typed 경계를 사용한다.
- 생성 source는 Feature fixture에 `featureResolversFactory`가 없으면 통과하는 테스트를 만들지 않고 생성 전 실패한다.
- 공개 API baseline과 symbol budget은 위 의도된 계약 변경만 반영했다.

## 열린 외부 gate

- 정확한 Xcode 26.6 / Swift 6.3.3 Release와 독립 consumer 검증.
- 실제 macOS/iPadOS window 및 visionOS immersive allow/reject/cancel 조작, canonical state와 화면·로그 대조.
- 사용자 승인 후 후보 commit/push, 해당 SHA의 필수 원격 CI와 remote parity.
- 별도 승인된 exact 6.0.0 tag, release notes, DocC 및 원격 version consumer 검증.

> 2026-09-11 후속 정정: [열두 번째 재검토](6.0.0-twelfth-review.ko.md)에서
> Feature completion/lifetime/plan/replay, system repair queue, conditional availability의
> 추가 결함 6건이 재현됐다. 따라서 이 문서의 묶음 PASS는 당시 실행한 범위의 기록으로만
> 유지하며, 현재 판정은 다시 구현 진행 중이다.

따라서 이 시점의 판정은 당시 **로컬 구현 완료**까지만 가능했다. 후속 결함과 위 외부 gate 전에는 release-ready 또는 발행 완료로 판정하지 않는다.

기준 HEAD와 `origin/main`은 최종 확인 시 `0/0`이었고, 기존 `Derived/`, `InnoRouter.xcodeproj/` 및 과거 계획·증거 파일은 보존했다.
