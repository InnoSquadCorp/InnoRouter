## 증거 경계

- macOS의 실제 `NSHostingView` mounted/unmounted 경로는 정식 회귀로
  검증했다. 이는 visionOS native immersive UI 조작 증거를 대신하지 않는다.
- 전체 플랫폼 compile/interface는 Xcode 27.0/Swift 6.4에서 통과했다. 빌드 중
  Xcode가 생성한 `resource_bundle_accessor.swift`에 scoped-import 경고가 있었지만
  저장소 소스 경고나 실패는 아니었다.
- 현 후보의 Xcode 26.6/Swift 6.3.3 및 원격 exact-SHA CI 증거는 아직 없다.
- 현재 결과는 기준 revision 위의 미커밋 로컬 patch다. 따라서 새 후보 SHA는
  아직 존재하지 않으며 직전 revision의 원격 성공을 이번 patch의 증거로 승계하지 않는다.
- 이 문서는 로컬 구현·검증 기록이며 commit, push, tag, release 또는 배포
  승인을 의미하지 않는다.
