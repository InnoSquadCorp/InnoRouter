기존 성공 로그를 무효화하거나 삭제하지 않는다. 아래 열린 변형은 이번 표가 최신 판단이다.
이전 문서의 전체 완료 표시는 이 재개방 범위를 덮어쓸 수 없다.

유지관리자 승인 여부, 구현 여부, 실제 검증 여부는 서로 다른 상태다. 로컬 수정 완료는 배포 완료가 아니다.
기존 intentional known issue와 이번 새 실패를 구분하고, 미실행 gate나 남은 반례를 숨긴 채 “최종”으로 기록하지 않는다.

최종 검증은 Apple Swift 6.4 / Xcode 27에서 수행했다. pinned Swift 6.3 자체, 실제 기기·Simulator
native lifecycle, 실제 채택 앱, 원격 release-commit CI, exact-tag 소비는 확인하지 않았다. 로컬
수정 완료는 배포 완료가 아니며 commit·push·tag·release는 수행하지 않았다. 기존 혼합 작업트리의
관련 없는 변경은 정리하거나 stage하지 않았다.
