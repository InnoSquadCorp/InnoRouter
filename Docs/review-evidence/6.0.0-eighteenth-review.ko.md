# InnoRouter 6.0.0 — 18차 재검토 수정 증거

검증일: 2026-09-14 KST

## 정정 (2026-09-15)

이 문서의 **Q01 전체 종료 보장은 재개방되었다.** 같은 후보의 `RouterFifteenthReviewRegressionTests`에 스트림 종료를 종료 조건으로 처리하지 않는 대기 루프 두 개가 남아 있었고, 이벤트 하나를 누락시키면 테스트가 유한 시간에 실패하지 못하고 무한 회전한다. 재현·수정 증거는 [19~21차 검토 수정 증거](6.0.0-nineteenth-review.ko.md)에 있다. 아래 Q01 행의 다른 항목과 F01~F06·Q02의 실행 기록은 그대로 유지한다.

## 판정

17·18차 통합 계획의 제품 결함 F01~F06과 검증 공백 Q01~Q02를 수정·보강했고, T00~T06 및 AC01~AC21의 로컬 범위를 완료했다. 판정은 **코드 수정 및 로컬 자동 검증 완료**다. pinned toolchain, exact commit 원격 CI, 실제 채택 앱/native UI·접근성, commit·push·tag·release는 별도 미완료 게이트다.

## 설계·호출자 영향

### Restoration activation

- 첫 suspension 전 observation과 시작 revision을 예약한다. `.alreadyActive`는 snapshot restore 완료가 아니라 유효한 observation이 성립했음을 의미한다.
- stop/cancellation 뒤의 worker, await 완료, attach 반환, caller 반환은 이전 generation의 상태·owner를 변경할 수 없다.
- 한 caller의 취소는 자기 claim만 제거하며, 다른 attachment/manual owner가 있으면 공유 복원과 observation을 유지한다. 마지막 owner 제거는 task·observer·예약 save를 정리한다.
- public symbol은 추가하지 않았다. 파일 책임을 유지하기 위해 snapshot storage 구현만 `RouterSnapshotStorage.swift`로 분리했다.

### Deferral expiration

- 같은 public deferral ID를 정상 재사용할 수 있다. 만료 권한만 개별 등록 token에 귀속된다.
- 옛 callback은 새 요청·timer를 제거하지 않는다. 현재 등록만 자기 TTL에 한 번 terminal 처리된다.
- public API와 기존 TTL 없음·0 이하, resolve/cancel/reset/evict/re-defer 계약은 유지한다.

### Macro-first feature

- 연관값 catalog-name case와 instance member는 허용하고, 직접 parameterless case/static member의 실제 충돌만 진단한다.
- bare `Self` feature payload는 선언 당시 부모 route 타입을 뜻한다. 생성된 typed mapping/catalog가 직접·nested·generic route에서도 같은 타입 의미를 유지한다.
- 기존 조건부 `@FeatureRoute` E065와 availability-negative 계약은 유지한다. 비활성 조건부 충돌은 빌드를 막지 않고 활성 충돌은 compiler 진단으로 실패한다.

## AC 연결

- AC01~02: cancellation-safe runtime dependency, finite storage gate, suite deadline, cleanup assertion으로 Q01을 닫았다.
- AC03~09: 18차 activation 5개 회귀와 기존 restoration/16차 mounted-host 조합이 reservation, stop/restart, caller 반환, manual/manual, host/manual, retry, 자연 detach와 save를 검증한다.
- AC10~12: token-aware same-ID/different-ID parameterized test와 기존 reset/resolve/evict/re-defer 회귀가 새 timer 보존·단일 만료·잔여 정리를 검증한다.
- AC13~17: expansion, behavior, 일반 Swift 대조, 외부 debug/release consumer가 overload, 실제 충돌, 부모 `Self`, nested generic, 조건부 compiler 행렬을 검증한다.
- AC18~19: 새 suite를 전체 test와 sanitizer filter에 포함했고, 16차 계획·증거에 후속 정정 이력을 추가했다.
- AC20~21: 동일 scoped 후보의 전체 local gate와 caller 관점 재검토, 후보·환경·보존·미실행 경계를 이 문서에 연결했다.

## 남은 배포 게이트

- 이 Mac에는 Xcode 27.0 / Swift 6.4만 확인되었다. pinned Xcode 26.6 / Swift 6.3.3 compiler로 이 후보를 실제 빌드·테스트해야 한다.
- exact commit SHA의 원격 필수 CI와 tvOS/watchOS/visionOS simulator runtime을 확인해야 한다. 로컬 compile/interface 성공은 runtime 성공이 아니다.
- 실제 downstream revision의 migration/build/runtime, native visionOS immersive, iPad form factor, 접근성/VoiceOver 검증이 남아 있다.
- commit·push·tag·release는 수행하지 않았다. 별도 요청과 release 승인이 있어야 진행한다.

따라서 F01~F06/Q01~Q02의 알려진 반례는 현재 scoped 후보에서 닫혔고 로컬 품질 게이트도 통과했다. 그러나 이 문서를 모든 플랫폼·입력의 무결함 선언이나 6.0.0 발행 완료 증거로 승격하지 않는다.
