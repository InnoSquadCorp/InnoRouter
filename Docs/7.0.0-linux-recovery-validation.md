The host shape validator is package-internal groundwork. It validates explicit
node kinds, branch/column mappings, inactive declared branches and an explicit
orphan policy. It neither proves a root/label view exists nor installs a Store or
native-host policy. Mandatory existing-host behavior, typed recovery/creation,
atomic plan+contract changes and scoped rendering APIs await the explicit API
approval. Root-only optional checks are not §5.2 completion.

Finite defaults remain provisional. Counts cover specified owner-held queues,
operations, built-in metadata and encoded inputs; they do not measure opaque
application Route/Value storage or make arbitrary application callbacks safe.
Weak scope bookkeeping can scale with distinct caller-retained projections.
Current graph lifetime subscriptions no longer disappear when a temporary scope
is collected, and oversized paths are rejected before hashing/caching/admission.

setup, zero-test and fixture-selection failures are not regression witnesses.
