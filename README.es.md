# InnoRouter

> Esta traducción de la API 5.x queda archivada. La documentación canónica de
> InnoRouter 6 está disponible por ahora en [inglés](README.md) y
> [coreano](README.ko.md).

`RouterStore`, `RouterState` y vocabulario `RouterAction`.
