# Macro diagnostics

@Metadata {
  @PageKind(article)
}

Use the stable code printed at the start of an InnoRouter macro diagnostic to
find the recovery without depending on the compiler's surrounding wording.
Errors prevent the macro from emitting an incomplete routing contract.
Warnings identify valid code whose generated behavior is likely surprising or
whose explicit declarations are redundant.

## Enum and case-path declarations

| Code | Severity | Meaning and recovery |
|---|---|---|
| `InnoRouterMacro.E001` | Error | `@Router`, `@Routable`, `@CasePathable`, or `@SceneRouter` is attached to a non-enum declaration. Change a struct or class to an enum with the Fix-It, or refactor an actor or protocol manually. |
| `InnoRouterMacro.E002` | Error | `@Routable` or `@CasePathable` is attached to an enum with no cases, so no case paths can be generated. Add a case or remove the macro. |
| `InnoRouterMacro.E003` | Error | `@Routable` or `@CasePathable` is attached to a generic enum. Move generic data into a concrete payload wrapped by a non-generic enum. `@Router` itself supports constrained generic routes. |

## Router destinations

| Code | Severity | Meaning and recovery |
|---|---|---|
| `InnoRouterMacro.E004` | Error | `@Router` cannot find `var destination: some View` directly inside the enum. Add the property to the enum rather than an extension. |
| `InnoRouterMacro.E005` | Error | `destination` has the wrong shape. Make it one get-only, instance, computed `var destination: some View` declaration. |
| `InnoRouterMacro.E006` | Error | A manual `static destination(for:)` conflicts with the witness generated by `@Router`. Remove the function, or remove `@Router` and conform manually. |
| `InnoRouterMacro.W001` | Warning | An `@Router` enum has no route cases. The host can render only its root. Add cases or remove the macro if that is not intentional. |
| `InnoRouterMacro.W002` | Warning | `DestinationRoute` is written explicitly even though `@Router` supplies it. Remove the conformance. |
| `InnoRouterMacro.W003` | Warning | `Route` is written explicitly even though generated `DestinationRoute` inherits it. Remove the conformance. |

## Tabs

| Code | Severity | Meaning and recovery |
|---|---|---|
| `InnoRouterMacro.E007` | Error | `@TabItem` is not attached to an enum case. Move it to one case inside an `@Router` enum. |
| `InnoRouterMacro.E008` | Error | The nearest enclosing enum does not use `@Router`. Add `@Router` to that enum or remove `@TabItem`. |
| `InnoRouterMacro.E009` | Error | Only some cases have `@TabItem`. Annotate every case or remove every tab marker. |
| `InnoRouterMacro.E010` | Error | One case has multiple `@TabItem` annotations. Keep exactly one. |
| `InnoRouterMacro.E011` | Error | An annotated declaration contains joined cases. Split it so each `@TabItem` annotates exactly one case. |
| `InnoRouterMacro.E012` | Error | A tab case has associated values and cannot participate in generated `CaseIterable` conformance. Move payload state outside the tab enum. |
| `InnoRouterMacro.E013` | Error | The title or system image is not a nonempty, noninterpolated string literal, or the argument labels are invalid. Use `@TabItem("Title", systemImage: "symbol")`. |
| `InnoRouterMacro.E014` | Error | A tab case is conditionally available. Keep one stable `allCases` inventory. |
| `InnoRouterMacro.E015` | Error | Tab cases or their attributes are declared inside conditional compilation. Declare the same tab set for every build configuration. |
| `InnoRouterMacro.E016` | Error | A manual member conflicts with generated `allCases`, `title`, or `systemImage`. Remove the member or all tab annotations. |
| `InnoRouterMacro.W004` | Warning | `RouterTab` is written explicitly even though `@Router` supplies it when tabs are marked. Remove the conformance. |
| `InnoRouterMacro.W005` | Warning | `CaseIterable` is written explicitly even though generated `RouterTab` inherits it. Remove the conformance. |

## Deep links

| Code | Severity | Meaning and recovery |
|---|---|---|
| `InnoRouterMacro.E017` | Error | `@DeepLink` is not attached to an enum case. Move it to one case inside an `@Router` enum. |
| `InnoRouterMacro.E018` | Error | The nearest enclosing enum does not use `@Router`. Add `@Router` to that enum or remove `@DeepLink`. |
| `InnoRouterMacro.E019` | Error | `@Router` deep-link argument labels or elements are malformed: for example, an element is an empty or interpolated string, a value is duplicated, or a nonliteral expression is used. Supply unique nonempty literal string elements using only `deepLinkSchemes:` and `deepLinkHosts:`. |
| `InnoRouterMacro.E020` | Error | A deep-link case exists while one or both scheme and host allowlist arrays are empty. Add nonempty values to both allowlists so origin checks fail closed. |
| `InnoRouterMacro.E021` | Error | One case has multiple `@DeepLink` annotations. Keep exactly one mapping. |
| `InnoRouterMacro.E022` | Error | An annotated declaration contains joined cases. Split it so each `@DeepLink` annotates exactly one case. |
| `InnoRouterMacro.E023` | Error | The path pattern is not a valid nonempty literal mapping. Correct the pattern described by the diagnostic. |
| `InnoRouterMacro.E024` | Error | A deep-link case is conditionally available. Keep the admitted URL inventory stable. |
| `InnoRouterMacro.E025` | Error | A deep-link case or marker is inside conditional compilation. Declare one stable mapping set for every build configuration. |
| `InnoRouterMacro.E026` | Error | An associated value has an unsupported declaration shape or cannot be parsed as a `DeepLinkParameterValue`. Use supported typed parameters; optional values are read from query items. |
| `InnoRouterMacro.E027` | Error | Path parameter names and required case payload labels do not match. Align the `:parameter` segments with the case labels; keep optional query-backed payloads optional. |
| `InnoRouterMacro.E028` | Error | An earlier mapping accepts every URL this mapping could accept, making the later case unreachable. Remove or distinguish the mapping, or put a narrower typed mapping first. |
| `InnoRouterMacro.E029` | Error | A manual `resolveDeepLink(_:)` conflicts with the resolver generated by `@Router`. Remove the function or the deep-link markers and conform manually. |
| `InnoRouterMacro.W006` | Warning | Scheme and host allowlists are present but no case uses `@DeepLink`. Add a mapping or remove the unused allowlists. |
| `InnoRouterMacro.W007` | Warning | `DeepLinkRoute` is written explicitly even though `@Router` supplies it for marked cases. Remove the conformance. |
| `InnoRouterMacro.W012` | Warning | Structurally overlapping mappings remain reachable only as ordered typed fallbacks. The marked earlier mappings are attempted first; the later mapping runs only after their typed conversions return `nil`. Verify that declaration order expresses the intended fallback. |

Literal paths outrank typed parameters, which outrank terminal wildcards. The
ordered-fallback rule described by `W012` applies within mappings that have the
same structural priority.

## Spatial scenes

Spatial diagnostics come from the opt-in `InnoRouterSpatial` product.

| Code | Severity | Meaning and recovery |
|---|---|---|
| `InnoRouterMacro.E030` | Error | `@Scene` is not attached to an enum case. Move it to one case inside an `@SceneRouter` enum. |
| `InnoRouterMacro.E031` | Error | The nearest enclosing enum does not use `@SceneRouter`. Add `@SceneRouter` or remove `@Scene`. |
| `InnoRouterMacro.E032` | Error | `@SceneRouter` and `@Router` are attached to the same enum. Keep only `@SceneRouter`, which already supplies route destinations. |
| `InnoRouterMacro.E033` | Error | `@SceneRouter` has no scene cases. Add at least one annotated case. |
| `InnoRouterMacro.E034` | Error | A generic scene enum cannot form one concrete app scene inventory. Use a non-generic enum and move generic state into scene view models. |
| `InnoRouterMacro.E035` | Error | Scene cases are declared inside conditional compilation. Keep one stable app scene inventory. |
| `InnoRouterMacro.E036` | Error | A scene case has conditionally compiled attributes. Keep its annotation set unconditional. |
| `InnoRouterMacro.E037` | Error | A scene case has no `@Scene` annotation. Add exactly one. |
| `InnoRouterMacro.E038` | Error | A scene case has more than one `@Scene` annotation. Keep exactly one. |
| `InnoRouterMacro.E039` | Error | An annotated declaration contains joined cases. Split it so each `@Scene` annotates exactly one case. |
| `InnoRouterMacro.E040` | Error | A scene case has associated values. Move instance state into the scene's view model; scene cases form a parameterless inventory. |
| `InnoRouterMacro.E041` | Error | A scene case is conditionally available. Keep the generated scene tree stable. |
| `InnoRouterMacro.E042` | Error | `@Scene` arguments, style, or explicit ID are invalid. Use `.window`, `.volumetric(width:height:depth:)`, or `.immersive(style:)` and an optional nonempty literal `id`. |
| `InnoRouterMacro.E043` | Error | A volumetric dimension is non-finite or not greater than zero. Supply positive finite metre values. |
| `InnoRouterMacro.E044` | Error | Two scene cases resolve to the same ID. Give every generated scene a unique stable identifier. |
| `InnoRouterMacro.E045` | Error | `@SceneRouter` cannot find `var destination: some View` directly inside the enum. Add it to the enum. |
| `InnoRouterMacro.E046` | Error | The scene `destination` property has the wrong shape. Make it one get-only, instance, computed `var destination: some View` declaration. |
| `InnoRouterMacro.E047` | Error | A manual `static destination(for:)` conflicts with the witness generated by `@SceneRouter`. Remove the function or compose scenes manually. |
| `InnoRouterMacro.E048` | Error | A manual `scenes` or other reserved member conflicts with generated scene composition. Remove the member or remove `@SceneRouter`. |
| `InnoRouterMacro.E049` | Error | `@SceneRouter` has unsupported arguments. Its only optional argument is the Boolean literal `immersiveLaunch:`; use `true` only when the first scene is immersive and the external launch manifest is configured. |
| `InnoRouterMacro.W008` | Warning | `DestinationRoute` is written explicitly even though `@SceneRouter` supplies it. Remove the conformance. |
| `InnoRouterMacro.W009` | Warning | `Route` is written explicitly even though generated `DestinationRoute` inherits it. Remove the conformance. |
| `InnoRouterMacro.W010` | Warning | The first case is immersive, so the generated primary host cannot dispatch before the system opens it. Put a window or volume first, or configure the immersive launch manifest and acknowledge it with `@SceneRouter(immersiveLaunch: true)`. |
| `InnoRouterMacro.W011` | Warning | `immersiveLaunch: true` is present while the first case is a window or volume. Remove the unnecessary acknowledgement. |

## Runtime wiring boundary

Macros validate source declarations, but they cannot inspect the SwiftUI
environment graph. `@EnvironmentRouter` and `@EnvironmentSceneRouter`
therefore resolve their matching authority lazily and apply
`EnvironmentMissingPolicy` only when an action is invoked. If a declaration
compiles but an action reports missing authority, check that the view is below
the matching generated host and uses the same route type.
